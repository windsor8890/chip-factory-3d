## 阅读方法

原尺寸逐张审图的基线 HTML 为 `56874338aabdcc60da9f3245407cdfe1b92deff251fdc6bf8ded49838120c0f2`。发布版调整了后处理帧缓冲和深度纹理绑定。重新截图后，逐章核对了采样秒数、分辨率以及 PNG 解码后全图 RGBA 字节的 SHA-256。22 对图共 45,619,200 个对应像素，全部一致。将横屏 01–11、竖屏 01–11 的每图摘要按此顺序拼接后再求 SHA-256，两版均为 `b4071626469da1fd49e854856556f85d8dc6473d74a5d5d492853f372983dab9`。

## 运动与几何

相机几何检测实际运行于上述 `56874338…120c0f2` 基线。发布版使用相同的模型、关键帧和运镜，沿用该次检测记录。在项目根目录运行 `python qa/camera_clearance.py` 可复测。脚本从本地 HTML 读取动画、相机和实例变换，对 0 至 37.25 秒按 60 Hz 采样，含起点和循环终点，共 2,236 个时间样本。横屏 HUD、横屏 2.39∶1 电影遮幅和原生竖屏各检查 2,848 个活动幕相机姿态，交接时两幕各计一次。每种取景 L0 至 L8 的样本数依次为 314、319、325、322、398、324、314、305、227。三种取景共 8,544 个姿态，穿入计数均为 0。[复测脚本](camera_clearance.py)

每个姿态检查相机原点、近裁剪面中心及四角共六点。脚本将各点变换到网格或实例的局部坐标，盒体用自身边界，其他几何按射线与三角面的交点奇偶判断内外。检测对象为可见、单材质、不透明度至少 0.75，且本地三个轴向厚度均至少 0.0001 场景单位的网格。该方法是离散的点采样，帧间运动、六点之间的表面以及透明、极薄物件靠画面复核。三次运行的控制台错误、警告及外部请求均为 0。

并排查看每处交接前后三帧。屋面和洁净层窗框保持同一透视方向。晶圆外缘、裸片角与接触孔的轮廓在相邻帧保持对位，周围布景随径向混合更替。两套图组中未见黑场、白闪、接缝闪烁或相机穿过实体。发布版再次采集八处交接后，横、竖两张六帧拼图分别与审图基线逐字节一致。[横屏交接](results/final/16x9/handoffs.jpg) · [竖屏交接](results/final/9x16/handoffs.jpg)
