# DF-02 芯片工厂 · 12 英寸晶圆厂

双击 **chip-fab-3d.html** 可进入实时三维厂区。点底栏的「巡游」，镜头会跟随 LOT-A7F3 从厂区屋面进入洁净室，经过黄光装载口和 EUV 反射光路，推进到约 50 nm 视域内的三层环绕栅晶体管，再沿原路径返回。全程 37.25 秒，共 11 章。[打开单文件作品](./chip-fab-3d.html)

在 GitHub 上打开 HTML 文件页，点击 **Download raw file**，保存后即可离线运行。[预览 11 章巡游](./qa/results/final/16x9/chapters.jpg)

## 浏览和操作

|操作|效果|
|---|---|
|点击左侧 L0–L8，或按数字 0–8|直接查看对应尺度|
|滚轮、双指开合|沿同一条尺度轴连续穿越|
|拖动、Shift + 滚轮|环视当前模型、改变本幕的观察距离|
|点击设备信标|查看设备编号、运行状态与批次。故障时设备停动作、亮红灯，恢复后写入事件列表|
|点击 LOT-A7F3、工程注释|查看工艺履历、曝光原理或当前剖面说明|
|D、L、H|切换公用工程数据层、投影标签、整个 HUD|
|空格、Esc|播放或暂停巡游、关闭详情。拖动、滚轮和点击也会停止巡游|
|V、F|切换横竖构图、切换全屏|
|顶栏 1× / 2× / 4×|改变设备、告警与工厂时钟的仿真速率|
|底栏「复位」|返回厂区初始镜头与仿真时刻|

厂区和洁净层可查看电力、超纯水、特气、排风与 OHT 路径。24 个设备工位使用同一确定性事件表驱动动作、信标和告警。黄光区照明、EUV 光束、晶圆薄膜及金属剖面分别采用独立材质。全片运营指标和工程模型均为「示意数据 · DEMO」。

竖屏单独计算相机取景、投影标签、标题和字幕位置。1080×1920 成片的章节标题为 65 px，正文为 30 px，顶部 10%、底部 22% 和右侧 16% 留给短视频平台界面。横屏成片在 1920×1080 画布内使用 2.39:1 遮幅。

## 场景与物理尺度

|尺度|观察对象|
|---|---|
|L0–L1|厂区道路、动力设施、厂房屋面，以及生产层、FFU 送风和回风夹层的垂直关系|
|L2|带孔地板、洁净室设备和运输 25 片晶圆的 FOUP。巡游视线随主角天车移动|
|L3–L4|吊带下降、晶圆盒与装载台接合、锡滴等离子体、真空多层膜反射光路和 4× 缩小投影|
|L5–L6|直径 300 mm、厚约 775 μm 的晶圆，随视角变化的膜色，目标裸片、逻辑分区及 SRAM 阵列|
|L7–L8|12 层铜互连与层间通孔、接触孔、源漏、三层硅沟道和环绕栅|

九幕使用各自的本地单位。交接时两个独立画面在同一个门对象上对位，以 0.64 秒的径向亮度遮罩展开。画面右缘的放大倍数从 ×1 归一到 ×10,000,000,000。底栏的物理比例尺按当前焦平面、视场角、画布高度和本幕单位计算。约 400 m 与约 50 nm 两端的实际比值为 8×10⁹。3 nm 表示工艺代号。

## 查询参数

将参数附在本地 HTML 文件名后，例如 `?stage=L4&instant=1`。多个开关可用 `&` 组合。

|参数|用途|
|---|---|
|`stage=L0` 至 `L8`、`sim=1\|2\|4`|指定起始视图、仿真速率|
|`tour=1`、`film=1`|带运营 HUD 巡游、仅保留片内标题和字幕的巡游|
|`ar=9x16`、`ar=16x9`|竖屏构图、横屏构图|
|`tourat=14.597`、`tourfast=1`|按秒定格某章、以 8 倍真实时钟巡游做 QA|
|`instant=1`、`still=1`|略过入场 veil、冻结手动观察时的仿真|
|`raw=1`、`lq=1`|查看直接转 sRGB 的线性场景结果、启用低画质配置|
|`nodata=1`、`nolabels=1`、`hideui=1`|关闭数据层、关闭投影标签、隐藏 HUD|
|`debug=1`|显示当前尺度位置、帧率和画质系数|
|`rec=1&fps=60&w=1080&h=1920&ar=9x16`|固定 DPR=1，按帧推进，直接输出含片内图文的完整画布|

## 逐帧录制与成片

录制脚本生成两版 H.264 成片。竖屏 1080×1920 保存为 `out/df02_9x16.mp4`，横屏 1920×1080 保存为 `out/df02_16x9.mp4`。

重录需要 Python、Playwright、NumPy、Pillow 和可用 GPU 的 Chrome 或 Chromium。编码器从系统 PATH 查找，也支持 imageio-ffmpeg 自带的可执行文件。`DF02_CHROME` 可指定浏览器程序路径。已有该环境时运行以下命令。

~~~sh
python qa/record.py
~~~

另建录制环境时可安装本次使用的 Python 包。若使用 Playwright 自带的 Chromium，再执行 `python -m playwright install chromium`。

~~~sh
python -m pip install playwright==1.58.0 Pillow==12.2.0 numpy==2.4.3 imageio-ffmpeg==0.6.0
~~~

默认逐帧保存 `frames/9x16/000000.png`、`frames/16x9/000000.png` 等文件，然后分别编码。每版 2,235 个视频帧，另存 1 个用于核对循环接缝的终点 PNG。编码参数为 `-r 60 -c:v libx264 -crf 14 -preset slow -pix_fmt yuv420p`。录制器核对每一步返回的序号，编码后完整解码并检查帧数与格式。测试短样可用 `python qa/record.py --format 9x16 --frames 12 --output-root qa/pilot`，短样另带 `_sample` 后缀。

`window.__rec.ready` 为真后，第一次 `step()` 绘制第 0 帧，之后每次绘制下一帧，返回帧索引。采样时钟 `time = frame / fps`。`frames` 包含终点验证样本，`done` 在其绘制后置真。浏览器的刷新频率和读回 PNG 的速度均不参与影片计时。
