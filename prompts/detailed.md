# DF-02 芯片工厂 · 从一粒沙到一颗芯片

你是一名资深创意开发者 / 3D 图形工程师 / 技术美术。请从零实现一个可直接交付的单文件 WebGL 作品：
**「DF-02 芯片工厂 · 12 英寸晶圆厂」**：一座先进逻辑芯片晶圆厂的实时三维数字孪生，
并附带一条**跨越 10 个数量级的一镜到底巡游**：从约 400 m 的厂区一路推进到视域约 50 nm 的晶体管，再无缝拉回。

本作是 DF-01 数字工厂（新能源汽车总装车间）的续作，质量必须明显更高，体现在三方面：
叙事（多尺度连续缩放 + 跟随一盒晶圆）、画面（洁净室光感、黄光区、光路、晶圆薄膜干涉）、
成片（竖屏原生 + 逐帧确定性录制）。

## 2. 视觉方向（必须准确）

**系列一致性（与 DF-01 相同）**：近黑暖石墨色虚空 #060708、摄影棚左上主光 + 右侧冷轮廓光、雾；
琥珀色数据层 #f2a73b；工业 HUD：中文为主、英文小注、Bahnschrift/DIN 感字体 + 等宽数字 + 微软雅黑，
hairline 细边框，不用圆角大卡片。状态色：运行 #9ed6b4 / 待机 琥珀 / 故障 #ff5638。

**DF-02 新增的视觉语言：**
- **洁净室**：暗场中一个"自发光的白色盒子"。FFU 天花均匀柔光，地面是带孔的华夫板，
  设备为象牙白 / 浅灰 PBR，与外围深色钢结构形成强对比。
- **黄光区**：光刻区笼罩在真实的暖黄光里（约 #ffc94d），比琥珀数据色更亮、更饱和，必须能明显区分。
- **光子色**：激光与 EUV 光路用冷白青 #cfeeff，是全片唯一的冷色强调，只出现在 L3–L4。
- **晶圆**：视角相关的薄膜干涉彩虹（自定义 shader，hue 随视角和法线变化），是全片唯一允许的多彩元素，只出现在 L5–L6。
- **微观（L7–L8）**：切换为"电镜 + 工程剖面"语言。铜互连为暖铜金属 #c8875a，介质层为半透明冷灰，
  硅为暗灰蓝，栅极金属为暖金；仍是暗色虚空背景，加浅景深。
- **禁止**：紫色渐变、霓虹赛博、纯饱和三原色、无纹理平白、低多边形玩具感、满屏粒子、过曝泛光。
- **后处理**：4× MSAA、高阈值 bloom、ACES、暗角；静态且按亮度遮罩的胶片颗粒（不用动态颗粒，否则暗背景会闪）；
  L0–L1 加轻微移轴（微缩感），L4–L8 加景深（显微感）；DPR 上限 1.75，帧率不足时自动降级（录制模式除外）。

有自己的本地单位、灯光微调和相机参数，由 `85-director.js` 统一调度；同一时刻只渲染 1 个 Stage，过渡时渲染 2 个。

## 4. 尺度过渡（核心技术，决定成败）

- **对数缩放**：跨尺度时，相机距离在 log 空间插值，保证视觉推进速度恒定，做出 "Powers of Ten" 的感觉。
- **交接帧对位**：每个 Stage 定义 `exitFrame`（镜头推进到某个"门"对象占满画面），下一个 Stage 定义 `enterFrame`，
  两者构图必须严格一致：同一主体、同屏占比、同运动方向。门对象依次为：
  L0 厂房屋面 → L1 洁净室层 → L2 光刻机 → L3 剖开的光路舱 → L4 晶圆台上的晶圆 → L5 一颗 die → L6 die 局部 → L7 最底层接触孔 → L8 晶体管。
- **混合方式**：两个 Stage 分别渲染到 RenderTarget，以门对象为中心，按径向 + 亮度遮罩向外扩散混合，
  时长 0.5–0.8 s，可叠加轻微的前后帧混合来模拟运动模糊。**禁止黑场硬切、白闪和构图跳变。**
- **尺度计 HUD**：竖向对数刻度尺，配实时比例尺（单位按 m / mm / μm / nm 自动切换），
  外加滚动数字「放大倍数 ×1 → ×10,000,000,000」。
- **交互**：浏览器里滚轮 / 双指可沿尺度轴连续穿越（scrub），也可以点 Stage 索引直接跳转。

## 5. 模拟系统 SIM（HUD 与 3D 状态的唯一数据源）

  所有设备对状态有可见反应（down 时停止动作、亮红灯，idle 亮琥珀灯）。
- 指标（全部标注"示意数据"）：月产能、WIP 片数、综合良率、设备 OEE、天车在线数、洁净度 ISO 等级 + 粒子计数、
  温度 22.0 °C / 湿度 45 %RH（实时微小波动）、超纯水电阻率 18.2 MΩ·cm、电力负荷 MW、告警列表。
- **主角晶圆盒**：`LOT-A7F3`，HUD 显示「工序 412 / 1186 · 当前层 M3 · 已用 41 天」，
  巡游中镜头全程跟随它。L2 中它挂在天车上，在 L3 落到光刻机 load port 上，叙事由它串起来。

## 10. 逐帧确定性录制（成片质量关键）

- `?rec=1&fps=60&w=1080&h=1920&ar=9x16`：时间严格等于 `frame / fps`；关闭自动降级与空闲漂移；固定 DPR；
  所有随机数都用种子，保证可复现。暴露 `window.__rec = { ready, frames, step(), done }`。
- `qa/record.py`：用 Playwright 有头 Chrome（启用 GPU），逐帧调用 `step()` 并截取 canvas，输出 `frames/*.png`。
  本机有 ffmpeg 时自动合成：`-r 60 -c:v libx264 -crf 14 -preset slow -pix_fmt yuv420p`，
  产出 `out/df02_9x16.mp4` 与 `out/df02_16x9.mp4`。首尾帧差 ≈ 0，可无缝循环。

## 11. 准确性（防懂行观众"打假"，必须遵守）

- 12 英寸晶圆直径 300 mm、厚约 775 μm；一个 FOUP 装 25 片；FOUP 由天花的 OHT 天车运送。
- 洁净室：FFU 天花送风，垂直单向流约 0.3–0.45 m/s，穿过华夫板回风；工艺区洁净度约 ISO 3–5 级；
  温度约 22 °C、湿度约 45 %RH，光刻区控温精度可达 ±0.1 °C；超纯水电阻率 18.2 MΩ·cm。
- 黄光区：光刻胶对紫外和蓝光敏感，所以照明过滤掉短波，呈黄色。
- EUV：波长 13.5 nm；直径约 20–30 μm 的锡滴每秒约 5 万个，被 CO₂ 激光（预脉冲 + 主脉冲）击中形成等离子体发光；
  光路全部是多层膜（Mo/Si）反射镜，置于真空中；掩模是反射式的；投影缩小 4×。
- 工艺：沉积 → 涂胶 → 曝光 → 显影 → 刻蚀 → 去胶清洗 → 离子注入 / CMP，循环往复；先进芯片要经历数十层掩模、
  上千道工序，制造周期约 3 个月；铜互连十余层。
- 「3nm」等是工艺代号，不等于晶体管的实际物理尺寸。字幕和标签必须体现这一点。
- 不使用任何真实公司、设备型号或 Logo；所有数值标注「示意数据 · DEMO」。

## 12. 性能

- 只渲染当前 Stage（过渡时加上相邻 Stage）；每个 Stage 控制在 < 250 draw calls、< 800k 三角面；桌面 60 fps。
- 重复物体（die 网格、FFU、FOUP、天车、SRAM 阵列、晶体管阵列）用 InstancedMesh；静态几何按材质合并；
  不在每帧分配几何、纹理或对象。
- L3 及以后的 Stage 在 L0 展示期间用 idle callback 分批构建，避免卡顿；首屏可交互 < 4 s；html 体积 < 2.5 MB。
